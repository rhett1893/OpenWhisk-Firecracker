Advanced Operating Systems Final Project Report

Extended Apache OpenWhisk 1.0.0 to execute serverless JavaScript functions inside Firecracker microVMs using Weave Ignite, improving an existing prototype by resolving compatibility, logging, and container reuse issues. Designed and conducted performance benchmarks comparing Firecracker microVMs against Docker containers across cold/warm starts, CPU operations, system calls, networking, and file I/O to evaluate virtualization overhead and performance trade-offs.
